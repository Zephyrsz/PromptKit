# PromptMaster 界面一致性优化验证

日期：2026-11-01。范围：SwiftUI 前端与最小构建修复。

## 用户任务与验收

- 浏览、搜索、筛选笔记和模板：首页与收藏使用相同组件；空资料库、空收藏和无结果分别提供说明；无结果可以重置全部筛选。
- 创建和编辑：标题、正文、标签使用统一的分组与输入表面；未保存更改取消时确认放弃；保存失败保留内容。
- 使用模板：全程使用“填空项”文案；填写、即时结果与复制状态一致。
- 管理标签：选择状态同时通过颜色、图形和辅助功能值表达；色板提供可读名称。
- 查看设置：列表图标与文字层级一致；存储状态和未开放功能如实呈现。

## 一致性规则

- 视觉：沿用石墨灰背景与低饱和蓝色；内容卡片 14pt、输入/操作控件 12pt、标签 8pt 圆角；系统语义字号与固定装饰图标分开处理。
- 组件：共用 `appCard`、`appInputSurface`、`appScreen`、`appGroupedList`、分组标题、关闭按钮、状态提示，以及主/次/删除操作样式。
- 交互：编辑表单使用取消/保存；标签即时选择使用完成；浏览弹窗使用关闭；删除继续使用系统确认；未实现入口禁用并标注“暂未开放”。
- 动效：只使用系统导航与弹窗转场；按压反馈改变透明度，不新增位移或弹簧动效。
- 内容：笔记、模板、填空项、标签在对应流程中使用相同术语；错误显示原因；筛选无结果提供恢复操作。

有意保留的差异：首页居中衬线斜体字标与既有 `home / 个人收藏 / 设置 / ＋` 底部布局；设置和标签采用原生分组列表容器。当前产品继续使用固定深色外观，不增加未实现的主题切换。

## 构建与自动验证

环境：Xcode 27.1（27A9275），Swift 5 语言模式，最低部署目标保持 iOS 16，实际运行在 iOS 27.0 模拟器。

专用模拟器：

- iPhone SE（第 3 代），375pt：`8A9CD1E0-E0F8-4FFC-BCE5-DB63B13160DC`。
- iPhone 18 Pro Max：`F5DA7C64-80D3-4B2F-88DA-11D89FDB6748`。

首先发现原有 `DataStore.toggleFavorite` 将局部变量误写为 `currenft`，但后续使用 `current`，导致无法编译；已仅修正该变量名。基线构建错误见 `.build/ui-consistency/baseline.log`。

新增草稿放弃保护和设置可用性测试在原界面下均失败，见 `Red.xcresult`，随后修复并通过。原有标签创建、导入筛选、编辑、收藏、复制、两种变量语法和重启持久化继续覆盖。

## 验证边界

- 真实 iPhone、iOS 16 运行时、VoiceOver 完整朗读路径、Switch Control、RTL 均未实际验证；横屏覆盖详情，未覆盖所有页面。
- 深色外观是既有产品约束；未新增浅色主题。
- UI 测试会创建专用模拟器中的测试内容；未清除现有用户资料库，也未接入后端、云同步、购买或导出功能。
- XCTest SDK 链接提示其运行库最低版本为 iOS 17，App 部署目标仍为 iOS 16；模拟器测试通过不能替代最低版本运行验证。
