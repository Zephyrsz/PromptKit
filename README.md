# PromptMaster iOS App

从 `prompt_shortcut_tools` Web 项目重构的 iPhone 提示词工具。SwiftUI，最低 iOS 16，Swift 5 语言模式。

## 本地运行

用 Xcode 打开 `PromptKit.xcodeproj`，选择 `PromptKit` Scheme 和 iPhone 模拟器，按 `⌘R` 运行，`⌘U` 执行测试。真机需在 Signing & Capabilities 中选择自己的开发团队。

**2026-10-22 起，日常使用完全基于 iPhone 本地 SQLite，不需要启动 Web 后端。**

## 笔记与模板

- **提示词笔记**：保存完整提示词，直接复制使用。即使正文含 `${示例}` 或 `{{示例}}`，也会原样复制，不要求填空。
- **模板**：保存含填空项的原始正文。支持 Web 的 `${变量}` 和旧 iOS 的 `{{变量}}`，支持中文变量名，按正文顺序自动识别和去重。填写时实时显示结果，填齐后可“生成并复制”。修改填写内容会立即更新结果。
- 首页和个人收藏均可按“全部／笔记／模板”筛选，支持搜索标题、描述、正文、使用说明和标签。
- 全部页面列出所有标签；勾选多个标签时匹配其中任一标签，再与搜索、内容类型、收藏范围同时过滤。标签后的数量表示当前搜索与分类下的内容数，不受其他已选标签影响。
- “全部”按笔记与模板分区，各显示自己的列表及数量；“笔记”“模板”只显示对应类型。标签可展开/收起，清除筛选只清除标签选择。
- 创建菜单提供“新建提示词笔记”和“新建模板”，编辑时可切换类型。模板至少需要一个填空项；笔记无需填空项。
- 编辑保留收藏、描述、使用说明和创建时间；详情始终显示最新保存的内容。
- 收藏的笔记与模板都出现在“个人收藏”。

## 标签

在“设置 → 标签管理”创建、删除标签，也可在编辑器的“选择标签”中直接创建。创建成功后，新标签自动选中；失败时保留输入并显示原因。

名称会去除首尾空白，空名称和重复名称不允许保存。仍被笔记或模板使用的标签不能删除，应先编辑相关内容移除引用。

## 存储

数据路径：

```text
SwiftUI → DataStore → SQLiteStore → Application Support/PromptKit/PromptKit.sqlite
```

使用系统 `SQLite3`，没有新增第三方依赖，不使用 UserDefaults 存储笔记。`prompts` 和 `tags` 保存正文、类型、标签、收藏、变量、描述、使用说明及时间。数组字段使用 JSON 文本；日期使用 Unix 秒；主键自增，不复用已删除记录的 ID。数据库通过 `PRAGMA user_version` 管理版本，当前为 v2，启用 WAL。v1 原有数据原地保留，新增 `import_receipts` 记录导入来源行与本地行的映射。

只有数据库写入成功才刷新界面并关闭编辑器。打开数据库失败时显示错误，不删除或重建现有用户数据库。关闭 App、重新启动、断网都可以使用已保存数据。

### Web 数据导入

2026-10-22 的 Web SQLite 快照随 App 打包在 `Resources/WebPrompts.sqlite`。启动时将 19 条内容（12 条笔记、7 个模板）和 13 个标签合并到本地 SQLite；为正文引用但原标签表缺失的 IT、健康、工具、生活、知识、编程、趣味补齐 7 个标签，因此新安装共有 20 个标签。未使用的源标签也完整保留。

导入使用只读源连接与目标写入事务，保留正文、描述、说明、收藏、类型、变量和原始时间，将 Prisma 毫秒日期转为本地秒日期、Tailwind 颜色转为十六进制。按名称合并已有标签，保留其本地颜色；内容使用新的本地主键，避免 ID 冲突。来源行收据确保重复启动不再导入已导入的记录，用户后续编辑或删除不会被恢复。失败时回滚整个导入，保留本地原有内容并显示错误，下次启动可重试。

更新内置快照：

```sh
python3 Scripts/export_web_snapshot.py
```

脚本通过 SQLite backup API 一致性读取 `../prompt_shortcut_tools/prisma/prompts.db`，不修改 Web 数据库。重新构建后可导入新来源行；已有来源行的变化不会覆盖 App 内编辑。这是本地验证用的一次性合并，不是实时同步。已有模拟器测试内容会保留，所以内容和标签总数可能更多。

`Services/APIService.swift` 作为历史 API 实现保留，当前 App 不依赖 Web 服务。任意文件导入、导出和跨设备同步仍未接入。

## 界面规范

首页使用居中的 PromptMaster 衬线斜体字标。底部固定为 `home / 个人收藏 / 设置 / ＋`，四项水平对齐；新增可创建笔记或模板。App 桌面显示名称为 PromptMaster，工程名、Bundle ID 与 SQLite 路径保留 PromptKit，以兼容现有安装与本地数据。

保留深色工具风格，采用石墨灰分层表面与低饱和蓝色强调色。字体统一使用 iOS 系统字体与中文系统回退，按标题、分组标题、正文、说明和辅助信息分层，支持动态字号。页面边距 20pt、分组间距 24pt、卡片内边距 16pt；首页与快捷页共用搜索框和内容卡片。

共享颜色、字体、间距与组件定义在 `Utils/ColorExtension.swift`。内容卡片统一 14pt 圆角，输入与操作控件 12pt，标签 8pt；主操作使用实心蓝色，次操作使用描边，删除使用带图标的柔和红色。设置、标签选择和标签管理使用原生分组列表，容器样式遵循系统。导航标题统一内联显示，首页字标保留品牌差异。

编辑、详情、填空项与标签弹窗共用表面、分组标题、关闭按钮和错误提示。标签自动换行，设置行、详情操作和卡片辅助信息在辅助字号下纵向排列。颜色选择同时提供名称、勾选和辅助功能状态；图标操作提供独立触控区域。

文案统一使用“笔记”“模板”“填空项”“标签”；表单保存使用“保存”，即时标签选择使用“完成”，只读弹窗使用关闭按钮。笔记/模板编辑存在未保存更改时，取消需确认放弃，拖拽关闭会被阻止；保存失败保留输入。空资料库、空收藏与筛选无结果分别提供对应提示，筛选无结果可一键重置。

设置复用分组列表与图标组件，显示实际的本地存储状态。尚未接入的导出、iCloud、Pro、反馈、评分与交流群入口明确标记“暂未开放”并禁用，避免显示虚假的激活、同步或导出成功状态。

## 测试

详见 [Xcode 本地构建与测试指南](XCODE_LOCAL_BUILD_AND_TEST.md)。

单元测试使用独立临时 SQLite 文件，覆盖离线保存、重开后数据完整性、编辑元数据、收藏、删除及 ID、重复或使用中的标签、写入失败保护、变量提取与替换，以及日期编码。

单元测试另覆盖完整源数据字段、v1 升级、导入失败回滚与重试、ID 冲突、导入后编辑/删除、重复启动去重，以及标签 OR、分类、搜索与收藏组合。

11 项 UI 测试覆盖主标签页、源 SQL 模板、标签多选与分区数量、标签创建与重启保留、笔记直接复制与编辑、收藏快捷访问和两种变量语法的实时预览，以及草稿放弃确认、未开放功能状态、颜色选择、空结果恢复和最大辅助字号。UI 测试在模拟器中创建带随机名称的测试记录；不要用日常使用的真实手机运行这些 UI 测试。
