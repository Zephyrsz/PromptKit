🚀 3 步开始使用：

【步骤 1】启动后端服务
  cd /Users/rgwei/pj/pj_my/prompt_shortcut_tools
  npm run dev

【步骤 2】在 Xcode 中创建项目
  1. 打开 Xcode
  2. File -> New -> Project
  3. 选择 iOS -> App
  4. Product Name: PromptKit
  5. Interface: SwiftUI
  6. 添加 PromptKit 文件夹中的所有 .swift 文件

【步骤 3】配置并运行
  1. 在 Info.plist 中添加网络权限（详见 INSTALL.md）
  2. 选择 iPhone 14 Pro 模拟器
  3. 点击运行 ▶️
